# Changelog

## 1.0.0

- Created separate behavior/resource packs with fixed identifiers and original generated pixel art.
- Added bounded anchored web traversal, short-lived thread rendering and wall grip.
- Added seven selectable gadgets, proximity Spider-Sense, action-bar status and help/settings forms.
- Added six full-body chest armor overlays and equipped-item-aware specializations.
- Added persistent research, repeatable timed patrols, safe starter/recovery tools and console recipe.
- Added strict TypeScript checks, automated tests, content/archive validation, deterministic packaging and GitHub Actions artifacts.
- In-game acceptance testing remains pending. Bespoke enemies, custom stations and cinematic content are not shipped.
